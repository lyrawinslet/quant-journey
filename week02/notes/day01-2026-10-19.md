## 4. 工具（30min）：VS Code 命令面板 `Ctrl+Shift+P` 跑通 10 个命令
打开任意 `.py` 文件（比如 `week02/scripts/stock_oop.py`），按 `Ctrl+Shift+P` 依次实操打勾：

- [ ] 1. **Format Document**（格式化文档，快捷键 `Shift+Alt+F`）：把乱序缩进自动排整齐
- [ ] 2. **Rename Symbol**（重命名符号，快捷键 `F2`）：把光标放在变量/函数名上，一键全文件安全改名
- [ ] 3. **Go to Symbol in Editor...**（转到编辑器中的符号，快捷键 `Ctrl+Shift+O` 或面板输入 `@`）：快速跳转到文件中的某个类或函数
- [ ] 4. **Go to Line/Column...**（转到行/列，快捷键 `Ctrl+G` 或面板输入 `:`）：直接跳到指定行号
- [ ] 5. **Go to Definition**（转到定义，快捷键 `F12`）：跳转到函数或类的定义处
- [ ] 6. **Python: Select Interpreter**（Python: 选择解释器）：确认当前使用的是 `quant` 环境
- [ ] 7. **Organize Imports**（整理导入，快捷键 `Shift+Alt+O`）：自动按字母序排列并清理未使用的 `import`
- [ ] 8. **Toggle Line Comment**（切换行注释，快捷键 `Ctrl+/`）：快速注释/取消注释选中行
- [ ] 9. **View: Toggle Terminal**（视图: 切换终端，快捷键 `` Ctrl+` ``）：打开或收起底部终端面板
- [ ] 10. **Git: Stage All Changes / Git: Commit**（Git 暂存与提交）：通过命令面板直接执行 Git 操作
